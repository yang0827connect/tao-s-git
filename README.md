# tao-s-git

一个使用 Git 管理的项目仓库。

## 快速开始

```bash
git clone https://github.com/yang0827connect/tao-s-git.git
cd tao-s-git
```

## 目录结构

```
.
├── README.md      # 本文件
└── .gitignore     # 忽略规则
```

## 提交约定

```
<type>(<scope>): <subject>
```

常用 type：`feat` 新功能、`fix` 修复、`docs` 文档、`refactor` 重构、`chore` 杂项。
